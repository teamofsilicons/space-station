# Silicon UI

The foundation and Button, Input, Card and Badge CSS are copied from the MIT-licensed
[Silicon UI registry](https://ui.teamofsilicons.com), also available in `silicon-ui/registry`.
`../silicon-ui.tsx` adapts these native surfaces to Solid instead of adding a second UI runtime.
The workspace retains native controls, keyboard behavior, reduced motion and its existing density.
The foundation supplies shared light/dark tokens, accents and squircle corners.

The MIT notice is included here and served at `/licenses/Silicon-UI.txt`.
